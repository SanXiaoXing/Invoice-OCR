# Version 1.0.0

## 主要功能

**SnapClaim**

- **PDF 发票自动识别**
  - 高铁电子发票：识别车次、出发站、到达站、日期、金额
  - 酒店确认单：优先扫描二维码提取住宿金额
  - 用车确认单：扫描二维码提取用车金额
  - 飞机确认单：识别机票金额
  - 其他发票：文本识别金额

- **费用报销单生成**
  - 自动汇总交通金额、住宿、市内交通等费用项
  - 支持出差天数设置，自动计算每日补助（¥100/天）
  - 自动计算预借金额、退补金额、总金额
  - 自动将总金额转换为大写金额

- **文件管理**
  - 支持批量上传多个 PDF 文件
  - PDF 文件合并（支持调整顺序、显示页数统计）
  - 一键导出合并 PDF 和报销单 Excel

- **界面主题**
  - 清爽办公风（默认）
  - 高对比效率风
  - 深色专业风
  - 柔和极简风
  - 企业可信风

- **出差日期管理**
  - 日历选择出发和返回日期
  - 自动计算出差天数
  - 支持手动微调天数

## 新增功能

- **二维码优先识别策略**：同程商旅酒店和用车确认单二维码直接包含金额，优先扫描二维码获取金额，避免 OCR 文本识别出错
- **多页 PDF 支持**：自动识别 PDF 每一页内容，支持跨页发票识别
- **实时进度反馈**：识别过程中显示进度条和状态提示
- **日志记录**：所有操作记录到 logs 目录，支持问题排查
- **首次启动引导**：首次运行时自动弹出关于对话框，介绍应用功能
- **规则配置**：支持通过 `rules.yaml` 自定义发票类型识别规则和字段提取模式
- **金额提取**：支持多种金额格式识别（价税合计、实付金额、费用合计、￥符号等）

## 注意事项

- 二维码识别对扫描质量有一定要求，请确保 PDF 页面清晰
- 高铁票仍使用文本识别，建议上传文字清晰的 PDF
- 支持导出格式：合并 PDF、报销单 Excel（.xlsx）
- 默认补助标准为 ¥100/天，如需调整请修改代码配置
- 推荐使用 Windows 系统运行，其他系统未经过充分测试
- 支持键盘快捷键：
  - Ctrl+M：合并 PDF
  - Ctrl+E：导出报销单
  - Ctrl+Shift+E：一键导出
  - Ctrl+Shift+A：关于对话框
